What I Write About?

รวมบทความ เทคนิค และมุมมองส่วนตัวเกี่ยวกับการใช้งาน Excel, Power BI, Analytics และ AI Tools สำหรับจัดการและวิเคราะห์ข้อมูล สำหรับองค์กร

Microsoft Excel

แชร์เรื่องราวเกี่ยวกับ Excel ตั้งแต่สูตร, Dynamic Array, Power Query, VBA, Office Scripts และเมนูการใช้งานที่มีประโยชน์ในการทำงาน

Power BI

แชร์เรื่องราวเกี่ยวกับการสร้าง Dashboard หรือรายงานบน Power BI, การเขียน DAX และการเล่าเรื่องด้วยข้อมูล เพื่อเปลี่ยนข้อมูลดิบให้กลายเป็นข้อมูลเชิงลึกที่เข้าใจง่าย

AI Tools

แชร์เรื่องราวเทคนิคการใช้งาน Copilot in Excel และ Copilot in Power BI และ AI Solutions อื่นๆ

Data Analytics

แชร์เรื่องราวและเทคนิคด้าน Analytics, Machine Learning และ Analytics Framework ในโลก Corporate ของแต่ละ Use Case ต่างๆ ในมุมมองและประสบการณ์ส่วนตัว
