Book Review

รีวิวหนังสือ DAX FOR HUMANS ที่ทำให้ DAX เข้าใจง่ายกว่าที่คิด

ไปสะดุดกับหนังสือ Power BI ปกจัดจ้านเหมือนโปสเตอร์หนัง Sci-Fi เข้าโดยบังเอิญ แล้วก็วางไม่ลงจนต้องซื้อมาเก็บไว้เอง

DR Reinvent Data Author • อ่าน 4 นาที

ช่วงนี้กำลังหาหนังสือ Power BI ดี ๆ จาก PACKT มาอ่านสักเล่ม แล้วก็ไปสะดุดกับเล่มนึงเข้า — "DAX FOR HUMANS"

ปกจัดจ้านเหมือนโปสเตอร์หนัง ไม่ใช่ตำราเทคนิค

ยอมรับเลยว่าตอนเห็นหน้าปกครั้งแรก นึกว่าเป็นโปสเตอร์หนัง Sci-Fi หรือ Comic Book มากกว่าหนังสือ Technical ด้วยซ้ำ 555 สีสันจัดจ้านมาก แล้ว Design ก็โดดออกมาจากหนังสือสาย Data ที่เห็นกันทั่วไปสุด ๆ 😆

แต่พอเห็นชื่อผู้เขียน — Greg Deckler — ก็ "อ๋อ" ทันที ถ้าใครอยู่ในวงการ Power BI หรือ DAX น่าจะคุ้นชื่อกันดี เพราะเป็นอีกหนึ่งคนที่ขึ้นชื่อเรื่อง DAX แบบสุดทาง

ตอนแรกตั้งใจว่าจะโหลด Preview มาอ่านเล่น ๆ ก่อน แต่พอเปิดอ่านไปได้ไม่กี่หน้า... กลายเป็นว่าวางไม่ลง!! (เว่อร์นิดนึง)

อธิบาย DAX จากมุมที่ไม่ค่อยเจอในหนังสือทั่วไป

สิ่งที่ชอบมากคือ หนังสือเล่มนี้พยายามอธิบายแนวคิด DAX ในอีกมุมหนึ่งที่ไม่ค่อยเจอจากหนังสือ DAX ทั่วไป หลาย ๆ จุดเหมือนได้ต่อจิ๊กซอว์ที่หายไปนาน

คนที่ใช้ Power BI มาสักพักน่าจะเข้าใจดีว่า DAX เป็นยาขมของหลายคน เพราะถ้าเทียบกับสูตร Excel แล้ว DAX มีเรื่อง Context, Filter Context, Row Context และของแถมภายใน Function อีกหลายอย่างที่ ค่อนข้างเป็น Black Box และเข้าใจยากมาก ๆ ถ้าเริ่มไปในระดับที่สูงขึ้น หลายครั้งสูตรทำงานได้... แต่เราไม่แน่ใจว่ามันทำงานอย่างไร หรือบางทีมันคำนวณผิดโดยที่ไม่รู้ตัวด้วยซ้ำ

ทำไม CALCULATE ถึงเป็น "หัวใจของ DAX"

ต้องย้อนไปถึงหนังสือ DAX ที่ได้รับการยอมรับมากที่สุดเล่มหนึ่งของโลกก่อน หลายคนน่าจะนึกถึง "The Definitive Guide to DAX" โดย Marco Russo และ Alberto Ferrari และหนึ่งใน บทที่สำคัญที่สุดของหนังสือเล่มนั้นก็คือฟังก์ชัน CALCULATE

ที่หลายคนยกให้เป็น "หัวใจของ DAX" เพราะสามารถเปลี่ยน Filter Context ระหว่างการคำนวณได้ และ เป็นพื้นฐานของสูตร DAX ขั้นสูงแทบทุกอย่าง ถ้าเคยเรียน DAX จากคอร์สหรือสถาบันไหนก็ตาม มีโอกาสสูง มากที่จะต้องเจอบท CALCULATE แน่นอน

หนังสือเล่มนี้

DAX FOR HUMANS โดย Greg Deckler จัดพิมพ์โดย PACKT — เหมาะกับใครก็ตามที่เคย รู้สึกว่า DAX เป็นยาขม และอยากเห็นอีกมุมมองที่อธิบายง่ายกว่าหนังสือ DAX ทั่วไปที่เคยอ่านมา

เมื่อ DAX FOR HUMANS แทบไม่พึ่ง CALCULATE เลย

โอเค พอย้อนกลับมาที่หนังสือ DAX FOR HUMANS สิ่งที่ทำให้เล่มนี้น่าสนใจคือ Greg เลือกนำเสนอ DAX จากอีกมุมหนึ่ง เป็นแนวคิดที่พยายามทำให้ DAX เข้าใจง่ายขึ้น และหลายตัวอย่างในหนังสือก็แทบไม่พึ่ง CALCULATE เลย!! แถมยังมี Use Case ให้เห็นเยอะมากกกก (ก ล้านตัววว)

จนบางครั้งอ่านแล้วรู้สึกว่า "อ้าว... ทำแบบนี้ได้ด้วยเหรอ 555"

ส่วนตัวอ่านหนังสือ DAX มาหลายเล่ม แต่ถ้าถามว่าเล่มไหนทำให้ DAX ดูเป็นมิตรกับมนุษย์มากที่สุด ตอนนี้ขอยกให้เป็นเล่มนี้จริง ๆ สมกับชื่อหนังสือ DAX FOR HUMANS

"DAX Is Easy, CALCULATE Makes It Hard."

และสุดท้ายก็อดใจไม่ไหว ต้องซื้อมาเล่มนึง 555

อยากอ่านบทความแบบนี้เพิ่มเติมอีกไหม

หวังว่าบทความทั้งหมดจะช่วยให้ผู้ที่เข้ามาสามารถได้ความรู้และเทคนิคดีๆ กลับไปใช้ประโยชน์ได้
