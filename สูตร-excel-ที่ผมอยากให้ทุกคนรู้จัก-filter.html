สูตร Excel ที่ผมอยากให้ทุกคนรู้จัก... FILTER

และเป็นหนึ่งในสูตร Excel ที่ผมชอบมากด้วยครับ

DR Reinvent Data Author • อ่าน 8 นาที
สวัสดีครับ กลับมาเรื่องเล่า Excel เหมือนเดิม ซึ่งก่อนหน้านี้ ผมมีเขียนบทความเกี่ยวกับ Excel 
"คีย์ลัด Excel มีเป็นร้อย… แต่ผมใช้จริงแค่ 6 ตัว!!" 

หากใครยังไม่เคยอ่านสามารถย้อนกลับไปดูได้ใน Link ข้างล่างได้เลยครับ :)
"คีย์ลัด Excel มีเป็นร้อย… แต่ผมใช้จริงแค่ 6 ตัว!!" 

ในบทความนี้ผมจะมาเล่าสูตร Excel ตัวนึงใน Excel 365 ที่ผมคิดว่ามีประโยชน์มากๆ และโดยส่วนตัวค่อนข้างใช้บ่อย และผมก็ได้เรียนรู้จากประสบการณ์หน้างานและเหล่ากูรูทั้งหลาย และเป็นหนึ่งในสูตร Excel ที่ผมชอบมากด้วยครับ 😊

นั่นก็คือ...

"FILTER" 

สูตร FILTER ผมมองว่าเป็นสูตรที่ทำให้ Excel สามารถแก้ปัญหางานได้หลากหลายมาก และคุณสมบัติของมันมีประโยชน์มากมาย 

ซึ่งในบทความนี้ผมจะเล่าถึงสูตรและ Use Case ต่างๆ ที่น่าจะเป็นประโยชน์กับทุกท่านที่มาอ่านครับ 😀

สูตร FILTER คืออะไร?
สูตร FILTER คือสูตรที่ใช้ดึงข้อมูลเฉพาะแถวที่ตรงตามเงื่อนไข ออกมาแสดงผลแบบอัตโนมัติ คล้ายกับการกดปุ่ม Filter บนแถบเมนู 

และตัวโครงสร้างของสูตร FILTER มีดังนี้ครับ
โดย Argument ที่ต้องใส่มีดังนี้ครับ
  • array คือช่วงข้อมูลที่ต้องการกรอง เช่น A2:D20
  • include คือเงื่อนไขสำหรับกรองข้อมูล โดยการเลือกคอลัมน์ เช่น B2:B20="ขาย"
  • [if_empty] คือค่าที่จะแสดงหากไม่มีข้อมูลตรงตามเงื่อนไข เช่น "No data" (ใส่หรือไม่ใส่ก็ได้ แต่ถ้าไม่ใส่แล้วไม่เจอข้อมูล จะขึ้น error #CALC!)
สมมุติว่าเรามีข้อมูลเป็นตารางประกอบด้วย 2 Column ได้แก่ Product และ Sales คราวนี้เรามาดูตัวอย่างกัน
ตัวอย่างที่ 1: การ Filter กรองด้วยเงื่อนไขเดียว 
สมมุติว่าเราต้องการกรองเฉพาะ Product = A ซึ่งสามารถเขียนสูตรได้ดังนี้
=FILTER(B6:C12,B6:B12="A")

เห็นไหมครับ ง่ายปลอกกล้วยเข้าปากเลยใช่ไหมครับ เผลอๆ ยังง่ายกว่าสูตร VLOOKUP อีก😁

.

โดย Key Concept ในการกรองเงื่อนไข คือ  B6:B12="A" เราแค่เลือกคอลัมน์ที่ต้องการ และใช้ Operator ต่างๆ ไม่ว่าจะเป็น =,<, >, <> บอกว่าต้องการกรองค่าอะไร

แต่อีกเทคนิคนึง ถ้าหากอยากจะรู้ว่าการทำงานของการกรองเงื่อนไขเป็นอย่างไร เราสามารถแกะสูตรโดยการคลุม B6:B12="A" จากนั้นกด F9 (หรือ fn+ F9) 

นี่คือเบื้องหลังการทำงานของตัว include ที่เป็นเงื่อนไขกรอง ว่าจริง ๆ แล้ว FILTER "มองเห็น" เงื่อนไขเป็นอะไร 

Excel จะไล่เช็คทีละแถวว่าเท่ากับ "A" หรือไม่ แล้วดูว่าแถวไหนเป็น TRUE ก็จะถูกดึงออกมา แถวไหนเป็น FALSE ก็จะถูกข้ามไป 

จึงเป็นเหตุผลที่ช่วงของ array กับ include ต้องมีจำนวนแถวเท่ากัน เพราะ Excel ต้องจับคู่กันทีละแถวนั่นเอง

ตามภาพประกอบข้างล่างที่ช่วยอธิบายให้เห็นภาพเข้าใจง่ายขึ้นครับ

โอเคร แล้วสมมุติว่าเราต้องการ Filter กรองด้วย"ตัวเลข"ล่ะ สมมุติว่าเราต้องการกรองเฉพาะ ยอดขายมากกว่า 15 โดยเขียนสูตรดังนี้

=FILTER(B6:C12,C6:C12>15)

แต่เดี๋ยวก่อนครับ!

เรากรองเงื่อนไขที่ตัวเลข แต่ทำไมถึงเอาหัวคอลัมน์มาด้วยล่ะ?  คำว่า "Sales" ทำไมถึงไม่โดนกรองออก

ในระบบของ Excel เมื่อเปรียบเทียบ ข้อความ กับ ตัวเลข  

"ข้อความจะถือว่ามีค่ามากกว่าตัวเลขเสมอ" 

ผลจึงออกมาเป็น TRUE จึงทำให้แถวหัวตารางก็หลุดเข้ามาในผลลัพธ์ 

โดยถ้าทดสอบเปรียบเทียบว่าข้อความมากกว่าตัวเลขหรือไม่ ผลลัพธ์จะเป็น TRUE เสมอ ตามตัวอย่างด้านล่างครับ

ถ้าหากเราต้องการกรองเงื่อนไขที่เป็นข้อความแล้วติดหัวคอลัมน์มาด้วย เราจะต้องเขียนสูตรอย่างไรดี?

ตัวอย่างที่ 2: การ Filter กรองด้วยเงื่อนรวมหัวคอลัมน์
สมมุติว่าเราต้องการอยากให้มีหัวตารางด้วย ใช้ VSTACK ต่อหัวไว้ด้านบนได้เลย
=VSTACK(B6:C6,FILTER(B6:C12,B6:B12="A"))

เราจะใช้สูตร VSTACK ซึ่งจะเป็นสูตรเลือกพื้นตามจำนวนที่เราต้องการครับ และทำการ "เชื่อม" ข้อมูลด้วย "," ซึ่งตามตัวอย่างเราเลือกหัวคอลัมน์ B6:C6 มาเชื่อมกับพื้นที่ที่สร้างโดยสูตร FILTER 

...................................................

หลังจากรู้จักพื้นฐานสูตร FILTER กันไปแล้ว คราวนี้มาต่อกันที่ท่าที่ใช้บ่อยที่สุดในงานจริง นั่นคือ การกรองด้วยหลายเงื่อนไขพร้อมกัน เช่น "อยากได้เฉพาะภาคกลางที่ยอดขายเกิน 2,000" หรือ "อยากดูภาคตะวันออกหรือภาคใต้"

หลักการจำง่าย ๆ มีแค่นี้ครับ

  • ใช้ * แทนคำว่า "และ" (AND) คือทุกเงื่อนไขต้องเป็นจริง
  • ใช้ + แทนคำว่า "หรือ" (OR) คือเงื่อนไขใดเงื่อนไขหนึ่งเป็นจริงก็พอ
  • แต่ละเงื่อนไขต้องครอบด้วยวงเล็บ ( ) เสมอ
คราวนี้เราจะข้อมูลตัวอย่างยอดขายแยกตามภาคและจังหวัด
ตัวอย่างที่ 3: เงื่อนไขแบบ "และ" (AND)
ขอเงื่อนไขแถวเฉพาะ "กรุงเทพ" และ ยอดขายมากกว่า 2,000 และเราสามารถกำหนดใน [if_empty] หากไม่มีแถวตามเงื่อนไข ให้แสดงข้อความ "No data" 
=FILTER(B18:C32, (B18:B32="Bangkok")*(C18:C32>2000), "No data")
ตัวอย่างที่ 4: เงื่อนไขแบบ "หรือ" (OR)
ขอเงื่อนไขแถวเฉพาะ "กรุงเทพ" หรือ "เชียงใหม่" ซึ่งเป็นคอลัมน์เดียวกันก็ได้
=FILTER(B18:C32, (B18:B32="Bangkok")+(B18:B32="Chiang Mai"), "No data")
ตัวอย่างที่ 5: เงื่อนไขแบบ "หรือ" (OR)
จากตัวอย่างที่ 4 นอกจากเงื่อนไขกรองแถวเฉพาะ "กรุงเทพ" หรือ "เชียงใหม่" แล้วถ้าหากเราต้องการ Sort เรียงลำดับยอดขายจากมาก-น้อยล่ะ สามารถทำได้โดยใช้สูตร SORT ครอบไปอีกทีครับ
=SORT(FILTER(B18:C32, (B18:B32="Bangkok")+(B18:B32="Chiang Mai"), "No data"),2,-1)

โดยสูตร SORT คือสูตรที่ใช้ เรียงลำดับข้อมูลแบบอัตโนมัติ ซึ่งสามารถเอาไปครอบ FILTER ได้ 

Argument ที่ใส่เพิ่มในสูตร SORT คือ 2 และ 1

  • 2 = เลือกคอลัมน์ลำดับที่สอง (หากเลือกคอลัมน์ลำดับแรก =1)
  • และสามารถกำหนดทิศทางการเรียงได้ โดยค่าระหว่าง 1 และ -1 โดยตัวอย่างด้วยกำหนด = 1 ซึ่งหมายถึงเรียงจากน้อย-มาก / แต่ถ้า -1 = มาก-น้อย

ตัวอย่างที่ 6: เงื่อนไขแบบ "หรือ" (OR)
จากตัวอย่างที่ 4 เหมือนเดิม แล้วถ้าหากต้องการเลือก 3 อันดับแรกล่ะ เราสามารถใช้สูตร TAKE ในการช่วย List 3 อันดับแถวแรกได้ครับ
=TAKE(SORT(FILTER(B18:C32, (B18:B32="Bangkok")+(B18:B32="Chiang Mai"), "No data"),2,-1),3)

โดยเงื่อนไขที่เพิ่มมา ใน SORT คือเลข 3 ซึ่งหมายความว่ากำหนด 3 อันดับแถวแรก

โอเครครับ นี่คือ 6 ตัวอย่างการใช้สูตร FILTER ตั้งแต่พื้นฐาน-ประยุกต์ ที่จริงมีตัวอย่างอีกเพียบเลยครับ 

แต่คิดว่าเท่านี้ ก็น่าจะเพียงพอสำหรับเอาไปใช้ประโยชน์ได้แล้ว ว่าไหมครับ😉

เดี๋ยวถ้ามีโอกาสจะเล่าตัวอย่างเกี่ยวกับ FILTER ให้ใน EP.2 อีกครับ :)
