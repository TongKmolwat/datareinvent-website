การคำนวณ Implicit VS Explicit Measure บน Power BI

การคำนวณทั้งสองแบบให้ "ตัวเลข" ออกมาเหมือนกัน แต่หลายคนงงกันว่า Implicit Measure และ Explicit Measure ก่อนจะอธิบายว่าจะใช้ยังไง ขออธิบายความหมายการคำนวณทั้งสองแบบก่อน

DR Reinvent Data Author • อ่าน 5 นาที
สำหรับการใช้งาน Power BI ปกติ เราจะไม่พ้นเรื่องการคำนวณที่เอามาใช้บน Visual ที่เราเลือก แต่ที่จริงแล้วรู้ไหมครับว่า การคำนวณ Power BI จะมี 2 รูปแบบ และเป็นศัพท์ที่วงการคนใช้ Power BI มักจะใช้เรียกกัน คือ

Implicit Measure และ Explicit Measure...

การคำนวณทั้งสองแบบให้ "ตัวเลข" ออกมาเหมือนกัน แต่หลายคนงงกันว่า Implicit Measure และ Explicit Measure คืออะไร ก่อนจะอธิบายว่าจะใช้ยังไง ขออธิบายความหมายการคำนวณทั้งสองแบบก่อน

Implicit Measure
Implicit Measure  คือการคำนวณแบบอัตโนมัติ (คล้ายกับ PivotTable ใน Excel ที่เราลาก Field หรือ Column มาใส่)

พูดง่ายๆ คือการคำนวณบน Power BI สร้างให้เราโดยอัตโนมัติ เพียงแค่เราลากคอลัมน์ตัวเลข (เช่น Sales Amount) ไปวางบน Visual แล้ว Power BI และเราอยากสามารถกำหนดได้เองว่า อยากจะได้ผลลัพธ์แบบไหน เช่น Sum, Average, Count เป็นต้น

ยกตัวอย่าง เอา Column: Unit ลากไปวางไว้ใน Visual ที่เราเลือก กรณีนี้เป็น Card Visual

ลองสังเกตดูครับ เวลาเราลากฟิลด์ตัวเลขลงไป จะมีสัญลักษณ์ Σ (Sigma) อยู่หน้าฟิลด์นั้น นั่นแหละคือสัญญาณว่ามันเป็น Implicit Measure

นอกจากนี้เรายังสามารถปรับการคำนวณ (Aggregation) ได้ด้วย เช่น Sum, Average, Count เป็นต้น

ข้อดีของมันเลย คือ เร็ว ง่าย ไม่ต้องเขียน DAX เลยแม้แต่บรรทัดเดียว เหมาะสำหรับกับการคำนวณหรือวิเคราะห์ข้อมูลเบื้องต้น

Explicit Measure
Explicit Measure คือ Measure ที่ เราเขียนขึ้นมาเองด้วยภาษา DAX โดยตั้งชื่อและกำหนด Logic อย่างชัดเจน 

พูดง่ายๆ คือการคำนวณบน Power BI ที่สร้างสูตร DAX ขึ้นมา และเราสามารถลากเอาไปวางบน Visual เหมือน Implicit Measure ได้เหมือนกัน

สมมุติผมสร้าง Measure ชื่อว่า Total Units (Explicit) จากนั้น โดยไปที่แถบ Data ข้างขวา> New Measure

Total Units (Explicit) = SUM([Unit])

สรุปก็ประมาณนี้เลย

นี่คือเรื่องราวความแตกต่างระหว่าง  Implicit Measure และ Explicit Measure.

ที่นี้ก็จะเกิดคำถามว่า... แล้วสถานการณ์ไหนควรใช้ Implicit Measure และ Explicit Measure...

คำแนะนำจากสาย Power BI Guru ส่วนใหญ่ให้ใช้ Explicit Measure เป็นหลักเสมอ

แต่กลายคนอาจจะคิดว่า เอ๊ะ ทำไมต้องทำสูตร DAX ให้ยุ่งยาก ก็ใช้ Implicit Measure อย่างเดียวก็ได้ เพื่อให้เห็นภาพ เดี๋ยวบทความถัดไปจะพูดถึงเคสให้เห็นภาพกันครับ


อยากอ่านบทความแบบนี้เพิ่มเติมอีกไหม
