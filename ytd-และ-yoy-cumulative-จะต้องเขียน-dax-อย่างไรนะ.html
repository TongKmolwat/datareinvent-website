YTD และ YoY Cumulative - จะต้องเขียน DAX อย่างไรนะ?

ช่วงนี้อาจจะห่างหายในการเขียน Blog ไปมั่ง เพราะติดภาระงานที่ท้วมท้น 😅

วันนี้ก็จะมาแชร์เทคนิคการคำนวณ DAX บน Power BI ที่เป็นที่นิยม นั่นก็คือ 

"YTD" 

.....................................

YTD คืออะไร?

YTD ย่อมาจาก Year to Date แปลตรงตัวคือ "ตั้งแต่ต้นปีจนถึงวันนี้" เป็นการรวมยอดสะสม (Cumulative) ตั้งแต่วันแรกของปี มาจนถึงจุดเวลาที่กำลังดูอยู่ ไม่ใช่ยอดเฉพาะเดือนนั้น

เพื่อให้เห็นภาพชัดเจน ขอยกตัวอย่างตารางด้านล่างนี้ครับ

คอลัมน์ซ้ายคือ "เดือนนี้ขายได้เท่าไหร่" คอลัมน์ขวาคือ "ตั้งแต่ต้นปีถึงสิ้นเดือนนี้ขายได้รวมเท่าไหร่"

พอถึง 1 ม.ค. ปีถัดไป ตัวเลข YTD จะรีเซ็ตกลับไปเริ่มนับใหม่จากศูนย์ นี่คือจุดต่างสำคัญจาก running total ทั่วไปที่บวกสะสมไปเรื่อยๆ ไม่มีวันหยุด

.

ซึ่งโดยปกติการคำนวณลักษณะแบบนี้ เราสามารถใช้สูตร Time Intelligence อย่าง DATESYTD หรือ TOTALYTD ก็ได้  

YTD A = CALCULATE ( [Total Sales], DATESYTD ( 'Calendar'[Date] ) )

YTD B = TOTALYTD ( [Total Sales], 'Calendar'[Date] )

จะเห็นว่าข้อมูลเมื่อนำมาใส่ใน Field และ Month เป็น Number จะมีหน้าตาแบบนี้
และมียอดสะสมจนถึงปีปัจจุบัน


แต่ถ้าหากจะเอา YTD มาเทียบกับปีที่แล้วล่ะ  

จะเป็นการคำนวณยอดสะสมปีนี้ เทียบกับยอดสะสมปีที่แล้ว ซึ่งเราจะเรียกว่า  

"YoY แบบ Cumulative"

ซึ่งในทาง Business จะใช้ประโยชน์เพื่อดูว่า "ตั้งแต่ต้นปีถึงตอนนี้ เราโตกว่าปีที่แล้วไหม" ซึ่งมีประโยชน์ในเรื่องดู Sizing Movement ของลูกค้า หรือการเติบโตยอดขายว่าผลลัพธ์ดีขึ้นไหมเมื่อเทียบกับปีที่ผ่านมา

.

ซึ่งแน่นอนว่าการเขียนด้วย DAX ไม่ใช่เป็นเรื่องง่าย ถ้าจะใช้สูตร Time Intelligence คำนวณ

ก่อนอื่น ให้เราแยกว่าการคำนวณแบ่งออกเป็น ปีปัจจุบัน และ ปีที่แล้ว ครับ 

โดยคราวนี้เราจะใช้ Sales Dataset ด้านล่างนี้ครับ ซึ่งจะเป็นข้อมูลปี 2024- 2025

โดยคราวนี้จะขอเลือก Line Chart เพื่อแสดงผล และ X-axis เป็นเดือนแบบ Number

ยังจำที่บอกตั้งแต่ต้นได้ไหมครับ

ว่าเราจะแยกการคำนวณ ปีปัจจุบัน และ ปีที่แล้ว ครับ ซึ่งหมายความว่าเราจะต้องเขียน DAX Measure 2 อันขึ้นมา สำหรับการคำนวณ YTD ปีปัจจุบัน และอีกอันเป็น YTD ปีที่แล้ว

ก่อนอื่นให้เราคำนวณยอดขายก่อน เพื่อจะได้นำไปใช้กับสูตร YTD 

Total Sales = SUMX(Trans_Volume, Trans_Volume[Unit/Sales] * RELATED(Product_List[Price/unit]))

ซึ่งเราจะคำนวณ DAX Measure โดยเอา SUMX ทำการคำนวณเอา Unit/Sales * Price/unit

ที่ถูกดึงมาจากอีกตารางด้วยสูตร RELATED

.

จากนั้นเราจะมาเริ่มเขียนสูตร  YTD ปีปัจจุบัน ดังนี้

Total Sales CY (Cumulative) = VAR _Today = TODAY() VAR _MaxDate = MAX('Calendar'[Date]) VAR _MonthStart = DATE(YEAR(_MaxDate), MONTH(_MaxDate), 1) RETURN IF( _MonthStart > _Today, BLANK(), CALCULATE( [Total Sales], DATESYTD('Calendar'[Date]) ) )


อธิบายสูตร Total Sales CY (Cumulative)

measure นี้ จะทำการคำนวณว่า "ณ สิ้นเดือนนี้ ปีนี้ขายสะสมไปแล้วเท่าไหร่ ซึ่งเราจะใช้ CALCULATE + DATESYTD

    CALCULATE(
        [Total Sales],
        DATESYTD('Calendar'[Date])
    )

นอกจากนี้ ยังมีเงื่อนไขพิเศษว่าเดือนที่ยังมาไม่ถึงให้แสดงเป็นค่าว่าง โดยใช้สูตร BLANK() ไม่ใช่ลากเส้นแบนไปจนสิ้นปี

เหมาะกับ line chart ที่มีแกน X เป็นเดือน และต้องการเส้นที่ไต่ขึ้นแล้วหยุดพอดีที่เดือนปัจจุบัน

จากนั้นก็จบด้วยอีกสูตร YTD ปีก่อน ดังนี้

Total Sales PY (Cumulative) = VAR _Today = TODAY() VAR _MaxDate = MAX('Calendar'[Date]) VAR _MonthStart = DATE(YEAR(_MaxDate), MONTH(_MaxDate), 1) RETURN IF( _MonthStart > _Today, BLANK(), CALCULATE( [Total Sales], SAMEPERIODLASTYEAR( DATESYTD('Calendar'[Date]) ) ) )


สูตร Total Sales PY (Cumulative)  เป็นสูตรฝาแฝดของตัว CY ต่างกันแค่บรรทัดเดียว 

เพียงเพิ่ม SAMEPERIODLASTYEAR ครอบ DATESYTD เพื่อเลื่อนช่วงเวลาถอยหลัง 1 ปี

...........................................

เมื่อคำนวณ 2 Measure เสร็จแล้ว จากนั้นก็เอา Measure ทั้งสอง Total Sales CY (Cumulative) และ Total Sales PY (Cumulative) มาใส่ใน Y-axis

เท่านี้ ก็จะได้ Line Chart ที่แสดง YoY แบบ Cumulative ตามที่ต้องการ

ทั้งหมดก็จบเพียงประการเท่านี้ หวังว่าจะเป็นประโยชน์ให้กับใครหลายคนๆ ที่มีงานคำนวณลักษณะแบบนี้นะครับ 😀

อยากอ่านบทความแบบนี้เพิ่มเติมอีกไหม

หวังว่าบทความทั้งหมดจะช่วยให้ผู้ที่เข้ามาสามารถได้ความรู้และเทคนิคดีๆ กลับไปใช้ประโยชน์ได้
