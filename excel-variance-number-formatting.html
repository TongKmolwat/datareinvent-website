Excel

การ Format ตัวเลขปีปัจจุบัน (ผลต่าง)

เทคนิคผสาน TEXT กับ CONCATENATE ที่เปลี่ยนตัวเลขเทียบปีต่อปีดิบๆ ให้กลายเป็นป้ายตัวเลขพร้อมใช้งานในรายงาน โดยไม่ต้องมานั่งพิมพ์คอมม่าทีละแถว

DR Reinvent Data Author • อ่าน 5 นาที

การปรับแต่ง Format ตัวเลขมีนัยยะสำคัญ ซึ่งทำให้คนดูสามารถที่จะตีความเข้าใจตัวเลขนั้นๆ ภายในระยะเวลาสั้นๆ ซึ่งเป็นสิ่งที่สำคัญมากๆ ครับ โดยเฉพาะอย่างยิ่ง การเปรียบเทียบตัวเลข ระหว่างปัจจุบันและปีก่อน เพื่อให้เห็นผลต่างตัวเลข เช่น ตัวเลขยอดขาย เราต้องการทราบว่าตัวเลขยอดขายของปีปัจจุบันมีการเติบโตหรือลดลง

ยอดตัวเลขปีปัจจุบัน (ผลต่าง)

รูปแบบที่ใช้กันแพร่หลายในรายงานฝ่ายการเงินและฝ่ายปฏิบัติการ คือการแสดงตัวเลขของปีปัจจุบัน แล้วตามด้วย ผลต่างจากปีก่อนในวงเล็บทันที

23,233 (912)

ตัวเลขนี้มาจาก 23,233 − 22,321 = 912 แล้วนำผลต่างมาติดไว้กับตัวเลขหลักเลย ทำให้คนดู ตีความได้ภายในเสี้ยววินาที ไม่ต้องเหลือบไปดูคอลัมน์อื่นหรือเปิดกราฟแยกต่างหาก ปัญหาอยู่ที่การสร้างมัน ขึ้นมา ถ้ามีแค่สี่ห้าแถวก็พิมพ์เองได้ไม่ยาก แต่ถ้าข้อมูลที่ต้องทำมีเป็นหลักร้อยแถว แต่ละแถวก็ต้องใส่ คอมม่าคั่นหลักพันเองทุกครั้ง งานนี้กินเวลาไปครึ่งค่อนวันแน่นอน

ทำไม CONCATENATE เพียงอย่างเดียวถึงไม่พอ

วิธีแรกที่มักจะนึกถึงคือฟังก์ชัน CONCATENATE ของ Excel ซึ่งใช้เชื่อมข้อความและตัวเลข เข้าด้วยกัน

=CONCATENATE(text1, text2, …, text_n)

เมื่อนำมาใช้กับป้ายตัวเลขผลต่าง จะเขียนได้ดังนี้

=CONCATENATE(D4," (",E4,")")

ลากสูตรนี้ลงไปทั้งคอลัมน์ ทุกแถวก็จะถูกเชื่อมเป็นข้อความเดียวกันจริง แต่พอลองดูผลลัพธ์กับตัวเลขที่มี หลักจริงจัง เช่น ตัวเลขหลักล้าน จะพบว่าออกมาเป็น 1234567 (91234) โดยไม่มีคอมม่าคั่นหลักพัน เลย และต่อให้เลือกคอลัมน์นั้นแล้วไปที่ Format Cells → Custom → #,##0 ก็ไม่มีอะไรเปลี่ยนแปลง เพราะเมื่อ CONCATENATE ทำงานเสร็จ ผลลัพธ์ที่ได้ไม่ใช่ตัวเลขอีกต่อไป แต่กลายเป็นข้อความ (Text) ซึ่งการจัดรูปแบบตัวเลขไม่มีผลกับข้อความ

จัดรูปแบบตัวเลขก่อน แล้วค่อยเชื่อมเข้าด้วยกัน

วิธีแก้คือจัดรูปแบบตัวเลขแต่ละตัวให้เรียบร้อยก่อน แล้วค่อยส่งข้อความที่จัดรูปแบบแล้วให้ CONCATENATE เชื่อมต่อ ซึ่งนี่คือหน้าที่ของฟังก์ชัน TEXT โดยตรง

=TEXT(value, format_text)

value คือตัวเลขที่ต้องการจัดรูปแบบ ส่วน format_text คือรูปแบบตัวเลขแบบ เดียวกับที่พิมพ์ใน Format Cells เช่น "#,##0", "0.0%", "$#,##0.00" เมื่อครอบตัวเลขทั้งสองตัวด้วย TEXT ก่อนนำไปเชื่อม ผลลัพธ์ก็จะได้ คอมม่ากลับคืนมา

=CONCATENATE(TEXT(D4,"#,##0"), " (", TEXT(E4, "#,##0"), ")")

ลากสูตรนี้ลงไปกี่ร้อยแถวก็ได้ ทุกแถวจะจัดรูปแบบตัวเองโดยอัตโนมัติ ไม่ต้องใส่คอมม่าเอง ไม่ต้องพิมพ์ซ้ำ ทีละบรรทัด

ตัวเลขที่คนดูต้องเพ่งอ่าน คือตัวเลขที่คนดูจะข้ามผ่านไปเฉยๆ

ทำให้สูตรยาวๆ อ่านง่ายขึ้น

เมื่อสูตรมีฟังก์ชันซ้อนกันสองชั้นและมีหลายอาร์กิวเมนต์ มันจะเริ่มอ่านเข้าใจยากในทันที ซึ่งมีผลตอนที่ ต้องกลับมาแก้ไขในภายหลัง ในช่องใส่สูตร การกด Alt + Enter จะช่วยขึ้นบรรทัดใหม่ได้ และ ตามด้วยการเว้นวรรคจะช่วยให้แต่ละอาร์กิวเมนต์อยู่คนละบรรทัด

=CONCATENATE(   TEXT(D4,"#,##0"), " (",   TEXT(E4,"#,##0"), ")" )

ผลลัพธ์ที่คำนวณได้เหมือนเดิมทุกประการ ต่างกันแค่ว่าอีกหกเดือนข้างหน้า ไม่ว่าจะเป็นตัวเราเองหรือ เพื่อนร่วมงานที่เปิดไฟล์นี้ขึ้นมา ก็จะเข้าใจได้ทันทีว่าสูตรนี้ทำอะไร โดยไม่ต้องมานั่งไล่ทวนใหม่

Tip

CONCATENATE ยังใช้งานได้อยู่ แต่ Microsoft ระบุว่าเป็นฟังก์ชันรุ่นเก่าแล้ว โดยแนะนำให้ ใช้ CONCAT, TEXTJOIN หรือเครื่องหมาย & แทน สำหรับกรณีนี้ การใช้ & ก็อ่านง่ายไม่แพ้กันและสั้นกว่าหนึ่งฟังก์ชัน: =TEXT(D4,"#,##0")&" ("&TEXT(E4,"#,##0")&")"

จัดการผลต่างที่เป็นค่าติดลบให้ดูสะอาดตา

ตัวเลขเทียบปีต่อปีมีทั้งเพิ่มขึ้นและลดลง และรูปแบบ "#,##0" ธรรมดาจะแสดงค่าที่ลดลงเป็น -355 อยู่ในวงเล็บ ซึ่งอาจทำให้อ่านผิดได้ง่ายเมื่อวางเทียบกับตัวเลขที่เป็นบวก การกำหนด รูปแบบตัวเลขแบบมีเงื่อนไขสำหรับค่าติดลบช่วยแก้ปัญหานี้ได้โดยไม่ต้องเขียนสูตรเพิ่ม

=TEXT(E4, "#,##0;(#,##0)")

ส่วนที่อยู่หลังเครื่องหมายเซมิโคลอนจะถูกใช้เฉพาะตอนค่าติดลบเท่านั้น ทำให้ตัวเลขที่ลดลงแสดงอยู่ในวงเล็บ ของตัวมันเอง แทนที่จะมีเครื่องหมายลบไปปนอยู่กลางป้ายที่มีวงเล็บอยู่แล้ว

เทคนิคนี้เอาไปใช้ได้ที่ไหนอีกบ้าง

เทคนิคนี้ไม่ได้จำกัดอยู่แค่ตัวเลขยอดขาย แนวทางจัดรูปแบบก่อนแล้วค่อยเชื่อมข้อความแบบนี้ เหมาะกับทุกจุด ในรายงานที่ต้องการให้ตัวเลขกับบริบทของมันอยู่ในป้ายเดียวกัน เช่น

  • สรุปผู้บริหาร: จำนวนพนักงานปัจจุบันพร้อมการเปลี่ยนแปลงจากไตรมาสก่อน
  • รายงานงบประมาณ: ยอดใช้จ่ายจริงพร้อมผลต่างเทียบกับงบที่ตั้งไว้ พร้อมนำไปวางในสไลด์ได้ทันที
  • แดชบอร์ด YTD: ยอดสะสมพร้อมผลต่างเทียบกับช่วงเดียวกันของปีก่อน ก่อนที่ข้อมูลจะถูกส่งต่อไปยัง Power BI

สร้างสูตรครั้งเดียว แล้วนำไปใช้ซ้ำได้โดยไม่มีต้นทุนเพิ่ม ไม่ว่าจะลากลงไปสี่แถวหรือสี่พันแถว การจัดรูป แบบก็จัดการตัวเองได้ทั้งหมด

อยากอ่านบทความแบบนี้เพิ่มเติมอีกไหม

หวังว่าบทความทั้งหมดจะช่วยให้ผู้ที่เข้ามาสามารถได้ความรู้และเทคนิคดีๆ กลับไปใช้ประโยชน์ได้
